    paginators

    Fancy paginators with a large amount of useful methods.

    Modules:

    • api –

      Base paginators made specifically for interaction with the api.

    • base –

      Base paginators.

    Classes:

    • BufferedPaginator –

      Paginator with a support for buffers.

      Paginator based on end_id cursors.
